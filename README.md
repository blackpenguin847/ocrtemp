# txtcrypt

쿼리·프로시저 같은 문자열을 **텍스트 형태의 암호문**으로 바꾸는 도구와, 그것을 되돌리는 도구입니다.
Rust로 작성했고 실행 파일은 두 개로 나뉩니다.

| 실행 파일 | 역할 |
|---|---|
| `encrypt.exe` | 문자열 → 암호문 텍스트 (한 줄, 영문·숫자·`-`·`_` 만 사용) |
| `decrypt.exe` | 암호문 텍스트 → 원래 문자열 |

## 빌드 (Windows)

[Rust](https://rustup.rs) 설치 후:

```
cargo build --release
```

`target\release\encrypt.exe`, `target\release\decrypt.exe` 가 생깁니다.
C 런타임을 정적으로 링크하므로(`.cargo/config.toml`) 별도 DLL 설치 없이 exe 만 복사해 쓸 수 있습니다.

## 사용법

### 클립보드로 쓰기 (가장 간단)

1. 암호화할 쿼리·프로시저를 복사합니다.
2. `encrypt.exe` 를 더블클릭합니다. 클립보드 내용이 암호문으로 바뀝니다.
3. 원하는 곳에 붙여넣습니다.

복호화도 같습니다. 암호문을 복사하고 `decrypt.exe` 를 실행하면 클립보드에 원문이 들어갑니다.
더블클릭으로 실행하면 결과를 볼 수 있게 Enter 를 누를 때까지 창이 닫히지 않습니다.

### 명령행

```
encrypt [-k 키] [-o 출력파일] [-c] [-s 글자수] [입력파일]
decrypt [-k 키] [-o 출력파일] [-c] [입력파일]
```

```
encrypt proc.sql                 암호문을 화면에 출력
encrypt proc.sql -c              암호문을 클립보드로 복사
encrypt proc.sql -o proc.enc     암호문을 파일로 저장
decrypt proc.enc -o proc.sql     원래 파일로 복원
type proc.sql | encrypt          파이프 입력
```

- 입력: 입력파일 → 파이프 → 클립보드 순으로 찾습니다.
- 출력: `-o` 파일 → 클립보드(`-c` 를 주었거나 클립보드에서 읽은 경우) → 화면 순입니다.
- 암호화하면 암호문 글자 수를 함께 알려줍니다.
- 파일·파이프 입력은 바이트 그대로 처리하므로 복호화 결과는 원본과 인코딩·줄바꿈까지 동일합니다.
  UTF-8이 아닌 파일(CP949 등)을 복호화할 때는 `-o` 로 파일에 저장하세요.
- 복호화할 때 암호문 중간에 섞인 공백·줄바꿈은 무시합니다.

### 긴 암호문 나누기 (`-s`)

메신저 글자 수 제한(예: 카카오톡 10,000자)에 맞춰 암호문을 여러 조각으로 나눕니다.

```
encrypt proc.sql -s 10000
```

- 각 조각은 `1/3:...`, `2/3:...` 처럼 번호가 붙고, 번호를 포함해 지정한 글자 수를 넘지 않습니다.
- 클립보드로 내보낼 때는 조각을 하나씩 복사하고, Enter 를 누르면 다음 조각으로 넘어갑니다.
- 복호화할 때는 조각들을 한꺼번에 넣으면 됩니다. 순서가 섞여도 되고, 조각 사이에
  보낸 사람 이름·시각 같은 다른 글자가 끼어 있어도 됩니다 (조각 앞뒤는 공백이나 줄바꿈으로 구분).
- 클립보드로 복호화할 때 조각이 모자라면 빠진 번호를 알려주고, 그 조각을 복사한 뒤
  Enter 를 누르면 이어서 받습니다.

## 키

- `-k 키` 또는 환경변수 `TXTCRYPT_KEY` 로 지정합니다. 암호화와 복호화에 같은 키를 써야 합니다.
- 둘 다 없으면 실행 파일에 내장된 기본 키를 씁니다. 이 경우 `decrypt.exe` 를 가진 사람은
  누구나 풀 수 있으니, 실제로 숨겨야 하는 내용에는 키를 지정하세요.

## 방식

deflate 압축(작아질 때만) → XChaCha20-Poly1305 암호화 → Base64URL 인코딩.
키는 `SHA-256(키 문자열)` 로 만들며, 암호문이 변조되거나 키가 다르면 복호화가 거부됩니다.
같은 내용을 암호화해도 매번 다른 암호문이 나옵니다.
